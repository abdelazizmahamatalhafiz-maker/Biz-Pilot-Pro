# 🚀 Biz-Pilot Pro — Smart Multi-Cash & Retail Management Dashboard

**Biz-Pilot Pro** is a modern, lightweight Business Intelligence and Point-of-Sale (POS) web application built with **Python**, **Streamlit**, and **Pandas**. Designed for shop managers, service providers, and entrepreneurs, it provides real-time financial tracking, strict multi-cash separation, and instant client receipt generation.

## ✨ Key Features
- **Secure Access Control**: SHA-256 hashed password authentication to protect sensitive business metrics.
- **Strict Multi-Cash Separation**: Separates **Shop Revenue**, **Personal Funds**, and **Client Deposits** to prevent accounting errors.
- **Real-Time Profit & KPI Tracking**: Automatic calculation of total revenue, net profit margins, and cash flow trends.
- **Instant Client Receipt Generator**: Built-in printable digital receipt generator ready for WhatsApp sharing or printing.
- **Data Portability & Backup**: One-click CSV export and local storage persistence.
